# Set Player 1.0.0

Set Player 1.0 is the first complete release of the native set library for
macOS and iPhone.

## Download

The GitHub release includes `Set-Player-macOS-arm64.zip`, an ad-hoc-signed
Apple Silicon macOS application. The iOS target can be built from source with
Xcode and your own development team.

## Set-centered library

- Searchable recording library with genre groups and Unfiled sets.
- Set descriptions, dates, durations, artwork, photos, video, and locations.
- Native player with a cached waveform, scrubbing, jump controls, volume, and
  full-screen media.
- Now and Next labels plus manual track marking.

## Rekordbox workflow

- Rekordbox history browser for sets, tracks, and statistics.
- Timeline matching between a recording and played-track history.
- Timed track rows with start positions and lengths.
- One-click Rekordbox launching.

## Performance extensions

- Live lyrics synchronized to Rekordbox.
- Rave Lyrics with beat, phrase, and curated visualizer presets.
- macOS app-audio recording.
- Per-app volume mixer.
- iPhone library synchronization.

## Validation

- XcodeGen project generation from `project.yml`.
- Native Apple Silicon macOS Debug and Release builds.
- iOS Simulator build with code signing disabled.
- Release archive validation and checksum generation.
