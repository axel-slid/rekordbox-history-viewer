# Set Player feature reference

## Library

- Discover or import recorded DJ sets from local audio files.
- Search by set name and organize sets into named genres.
- Store title, description, artwork, date, duration, location, and media.
- Keep an Unfiled section for recordings that have not been curated yet.
- Reveal the underlying files directly from the sidebar.

## Player and waveform

- Native AVFoundation playback with play/pause, 15-second jumps, scrubbing, and
  output volume.
- Full-set waveform cache with a visible playhead and track markers.
- Now and Next track labels mapped against the set timeline.
- Full-screen media view for artwork, photos, and video.
- Manual Mark Track control for correcting a set while reviewing it.

## Rekordbox

- Browse historical Rekordbox sets, tracks, and listening statistics.
- Match a recording against a played-track history session.
- Preserve track order, start position, and length as a timed setlist.
- Launch Rekordbox directly from the extension grid or player toolbar.

## Lyrics and visuals

- Live lyrics synchronized to the track Rekordbox is currently playing.
- Rave Lyrics mode for beat- and phrase-reactive presentation.
- Bundled Butterchurn visualizer runtime with curated presets.

## Recording and mixing

- Capture application audio into a new set recording on macOS.
- Inspect and control per-application volume.
- Move from the recording surface into the same library and metadata workflow.

## Memories and location

- Attach photos and videos to a set.
- Save a named map location and open the interactive map.
- Keep the set description, date, location, media, and timed tracks together.

## Continuity and appearance

- Sync the library with the iPhone companion.
- Native macOS and iOS SwiftUI targets.
- Multiple dark themes and accent treatments.
- Search, toolbar, and extension layouts that adapt to the current selection.
