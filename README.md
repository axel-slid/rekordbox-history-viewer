![Set Player animated product tour](docs/set-player-demo.gif)

Set Player turns recorded mixes into a visual, searchable memory library.

- play every set against its full waveform with track markers and now/next context
- match Rekordbox history to recordings for timed tracklists, live lyrics, and visuals
- attach photos, video, notes, dates, and map locations to the memories around each set
